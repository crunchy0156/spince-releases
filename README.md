# Spince

Your own music, Spotify-style, playing straight from your PC, with a phone app that plays it from anywhere.

**Download:** [the latest release](https://github.com/crunchy0156/spince-releases/releases/latest) → `Spince-Setup-x.y.z.exe` (Windows 10/11).

Spince updates itself from this page. This repository only holds the installers.
